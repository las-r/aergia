## Installing from GitHub
To install directly from the source code:
```sh
pip install git+https://github.com/las-r/aergia
```

## Installing locally
To install into a local folder:
```sh
git clone https://github.com/las-r/aergia
cd aergia
pip install -e .
```

## Usage
To run a file:
```sh
aergia yourfile.aer
```
