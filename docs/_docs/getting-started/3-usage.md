## Writing
In your IDE and folder of choice, make a new file called `hello.aer` and write or paste the following code:
```aergia
> "Hello, Aergia!"
```

## Running
Run your file from the terminal:
```sh
aergia hello.aer
```

If the `aergia` command isn't found, use it through Python instead:
```sh
python -m aergia hello.aer
```

You should see:
```
Hello, Aergia!
```
