An editor extension is optional, since Aergia files are plain text. VS Code is currently the only editor with Aergia v2 support.

## VS Code
The extension adds syntax highlighting for `.aer` files.

1. Download the latest `aergia-vscode-X.X.X.vsix` file from the [releases](https://github.com/las-r/aergia-vscode/releases).
2. Install it using either method:
   - Extensions panel: open the Extensions view, click the `...` menu in the top right, choose `Install from VSIX...`, and select the file.
   - Terminal: run `code --install-extension aergia-vscode-X.X.X.vsix`.
