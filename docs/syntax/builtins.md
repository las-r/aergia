# 9. Built-in Functions
Aergia comes with 2 builtin functions:
- `@in_arr:arr item:`: Returns 1 if `item` is in array `arr`, otherwise 0.
- `@join:str arr:`: Joins array `arr` with string `str`, identical to Python `str.join(arr)`
