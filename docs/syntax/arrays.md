# 5. Arrays & Indexing
Arrays are contiguous ordered collections. Indexing is zero-based.

| Token | Structure | Example |
| --- | --- | --- |
| `<...>` | Array Initialization | `= items <10 20 30>` |
| `:` | Index Resolution | `:items 0` (Resolves to `10`) |
