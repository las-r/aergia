# Aergia Support for VSCode
This extension adds syntax highlighting and some basic autocomplete configurations for the Aergia programming in Visual Studio Code.

## Installation
1. Go to [Releases on the GitHub repository](https://github.com/las-r/aergia/releases).
2. Look for the latest VSCode Extension release and download the .vsix package.
3. In VSCode, go to the Extensions sidebar.
4. Hit the three dots and top and select "Install from VSIX...".
5. Select the .vsix you downloaded.
