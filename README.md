## Tools
Aergia is provided with a few basic tools to aid in development:
- **Lethes**: A basic program minifier.
```bash
aergia --lethes <filename.aer>
```

- **Otia** (planned): A basic program formatter.
```bash
aergia --otia <filename.aer>
```
